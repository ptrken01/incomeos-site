What is Automatisch?

Automatisch is a self-hosted automation platform designed as an alternative to services like Zapier. It enables users to create visual workflows using a drag-and-drop interface, connecting various apps and services through webhooks. Unlike cloud-based solutions, Automatisch runs entirely on your own server, giving you full control over your data and automation processes.

The tool supports a range of integrations and provides a web UI for workflow creation, execution, and monitoring. It's built to handle internal automation tasks without requiring a SaaS subscription or cloud service dependency.

Why it's free for commercial use (AGPLv3 (core))

Automatisch is licensed under the GNU Affero General Public License version 3 (AGPLv3), which allows for commercial use while ensuring that any modifications or derivative works must also be distributed under the same license. This means businesses can use Automatisch in production environments, including for commercial purposes, without purchasing a separate license.

The AGPLv3 license ensures that if you modify or extend the software and distribute it, those changes must also be open-sourced under the same terms. However, since Automatisch is designed to run on your own infrastructure, this typically doesn't apply to end users who simply deploy it internally.

What we verified (our smoke test)

Our verification process involved running a basic setup using Docker Compose. The command `docker compose up` successfully initiated four containers, executed database migrations, and returned a 200 OK status code from the web UI at port 3000. This confirms that Automatisch can be quickly deployed and is functional with minimal configuration.

When to use it (and when not)

Use Automatisch when you need internal automation or orchestration without relying on third-party SaaS services. It's ideal for teams looking to avoid recurring subscription costs, maintain data sovereignty, or implement custom workflows within their own infrastructure.

Avoid using Automatisch if you require extensive app integrations beyond its current support, or if you're seeking a fully managed cloud-based solution with enterprise-grade support and SLAs.

How it compares to alternatives

Compared to Zapier, Automatisch offers the advantage of self-hosting, which is crucial for organizations with strict data governance policies. Unlike cloud-native platforms, it doesn't send your automation data to external servers. While Zapier provides a broader range of pre-built integrations, Automatisch focuses on core functionality and flexibility through its open-source nature.

Unlike proprietary tools, Automatisch's AGPLv3 license ensures that you retain control over your automation logic and can modify it as needed without vendor lock-in.

Get started (minimal, honest setup)

To get started with Automatisch:

1. Install Docker and Docker Compose

2. Clone the repository from GitHub

3. Run `docker compose up`

4. Access the web UI at http://localhost:3000

The setup process is straightforward, requiring only basic container orchestration knowledge.
