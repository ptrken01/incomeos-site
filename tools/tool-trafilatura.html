What is trafilatura?

Trafilatura is an open-source Python library designed for extracting clean, structured content from web pages. It specializes in retrieving the main article text, metadata (like titles and authors), and user comments from HTML documents. Unlike basic scraping tools, trafilatura focuses on content extraction accuracy by filtering out navigation elements, ads, and other non-essential page components.

The tool processes HTML input and outputs structured data that can be used for further analysis, indexing, or machine learning pipelines. It's particularly effective for handling complex web layouts and is commonly used in content aggregation, search engine indexing, and web research workflows.

What we verified (our smoke test)

Our verification process confirmed that trafilatura is already being actively used in production environments. Specifically, it's currently employed by the meta-loop's search ingestion pipeline, demonstrating real-world adoption and reliability in handling actual content extraction tasks within a complex information retrieval system.

When to use it (and when not)

Use trafilatura when you need reliable main-content extraction from articles, blogs, and news sites. It excels at identifying and extracting primary text while preserving metadata and comments. However, it's not ideal for extracting structured data from forms, interactive elements, or pages that heavily rely on JavaScript rendering. For such cases, tools like Selenium or Playwright would be more appropriate.

How it compares to alternatives

Compared to similar tools like newspaper3k or readability, trafilatura offers better handling of complex layouts and provides more consistent extraction quality across different website structures. While newspaper3k focuses primarily on news articles, trafilatura's approach works well across various content types. Unlike some alternatives that require extensive configuration, trafilatura provides sensible defaults that work out-of-the-box for most use cases.

Get started (minimal, honest setup)

To install trafilatura:

```bash

pip install trafilatura

```

Basic usage example:

```python

import trafilatura

Extract from URL

result = trafilatura.fetch_url('https://example.com/article')

extracted = trafilatura.extract(result)

```

The tool requires no special configuration for basic operations and integrates well with existing Python workflows.
