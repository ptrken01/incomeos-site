Implementation Example

Here's a working example using one of our prompts:

```python

import openai

import os

def generate_subject_line(topic, audience):

prompt = f"""

Generate 3 compelling subject lines for a newsletter about {topic}

targeting {audience}. Focus on curiosity gap and urgency.

Format as bullet points.

"""

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": prompt}],

temperature=0.7

)

return response.choices[0].message.content

Usage

subject_lines = generate_subject_line("AI tools for writers", "Substack authors")

print(subject_lines)

```

This code snippet demonstrates how to integrate prompts into your workflow using OpenAI's API. The system returns three subject lines per call, saving you 15+ minutes of brainstorming time.
