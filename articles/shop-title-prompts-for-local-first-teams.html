Implementation Tips

Each prompt includes specific variables like `[product type]`, `[material]`, and `[target keyword]` to ensure customization. For teams, create a template spreadsheet with these variables and populate them programmatically.

Example:

```python

import pandas as pd

from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

def generate_title(row):

prompt = f"Create an Etsy SEO-optimized title for a handmade {row['product']} with {row['pattern']}. Include 3-5 relevant keywords."

response = client.completions.create(

model="text-davinci-003",

prompt=prompt,

max_tokens=60

)

return response.choices[0].text.strip()

df = pd.read_csv('products.csv')

df['title'] = df.apply(generate_title, axis=1)

```

This approach generates 50+ titles in minutes instead of hours.
