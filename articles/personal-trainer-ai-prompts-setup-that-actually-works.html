Setting Up Your Prompt Library

First, create a dedicated folder structure:

```

/fitness-prompts/

├── client-programs/

├── social-posts/

└── dm-templates/

```

Store each prompt as a text file named descriptively. For example:

  • `client-program-template.txt`
  • `motivational-post.txt`
  • `welcome-dm.txt`

Your First Working Prompt

Here's a concrete example from the library:

```

You are a fitness coach. Create a 4-week beginner program for a client who wants to lose weight and build endurance.

Include:

1. Weekly schedule (3 days/week)

2. Warm-up routine

3. Main exercises with reps/sets

4. Cool-down

5. Progress tracking tips

Format as bullet points. Keep it simple.

```

Automated Workflow Setup

Create a bash script to automate prompt injection:

```bash

#!/bin/bash

PROMPT_DIR="/path/to/fitness-prompts"

CLIENT_NAME="$1"

OUTPUT_FILE="program_${CLIENT_NAME}.md"

echo "# Fitness Program for ${CLIENT_NAME}" > $OUTPUT_FILE

cat $PROMPT_DIR/client-programs/template.txt >> $OUTPUT_FILE

echo "" >> $OUTPUT_FILE

echo "## Client Notes" >> $OUTPUT_FILE

echo "- Goal: Weight loss and endurance" >> $OUTPUT_FILE

echo "- Experience: Beginner" >> $OUTPUT_FILE

```

This script generates a program template for any client. Run it with `./generate-program.sh John`.
