How to Set Up Your Launch Email Prompts

Here's the working setup using Notion + AI prompts:

1. Create a Notion database:

- Name: `Launch Sequence`

- Properties:

- `Email #` (number)

- `Subject Line` (text)

- `Content Prompt` (text)

- `AI Output` (text)

2. Copy-paste this Notion template into your database:

```markdown

Email {{Email #}}

Subject Line

{{Subject Line}}

Content Prompt

{{Content Prompt}}

AI Output

{{AI Output}}

```

3. Use these sample prompts for your launch sequence (you can find 50 ready-to-use prompts in the product):

```

[Email 1] Create a subject line that builds urgency for a course on "Mastering Python for Data Science" with off.

[Email 2] Write a 3-paragraph email introducing the course, highlighting 3 key benefits, and ending with a strong CTA to register now.

[Email 3] Draft a follow-up email that includes a testimonial from a student who completed the course, plus a limited-time discount.

```

4. Run the prompts using an AI tool like ChatGPT or Claude:

- Paste each prompt into your AI tool

- Copy the output back to your Notion database

- Schedule emails in your email service (Mailchimp, ConvertKit, etc.)
