Practical Implementation

Here's a working example using one of the prompts:

```python

Sample prompt structure for social caption generation

prompt_template = """

Create a workout caption for Instagram that includes:

  • Motivational hook about consistency
  • Specific exercise mention (e.g., 'squats')
  • Hashtag strategy (#30DayChallenge #FitWithPurpose)
  • Call-to-action encouraging comments

Workout: 3 sets of 12 squats, 30 seconds rest between sets

Caption should be 120-150 words maximum.

"""

Implementation example

def generate_caption(prompt_template, workout_data):

# This would connect to your AI API

response = openai.Completion.create(

engine="text-davinci-004",

prompt=prompt_template.format(workout=workout_data),

max_tokens=150,

temperature=0.7

)

return response.choices[0].text.strip()

```

The key is maintaining consistent parameters while allowing enough creative flexibility.
