Sample Implementation

Here's a working Python script that demonstrates how to use these prompts programmatically:

```python

import openai

import os

Initialize API

openai.api_key = os.getenv("OPENAI_API_KEY")

def generate_workout_caption(client_name, workout_type, difficulty):

prompt = f"""

Write a workout caption for {client_name} who just completed a {workout_type} session.

Difficulty level: {difficulty}

Include motivational language and specific achievements.

Keep under 150 words.

"""

response = openai.Completion.create(

engine="text-davinci-003",

prompt=prompt,

max_tokens=200,

temperature=0.7

)

return response.choices[0].text.strip()

Usage example

caption = generate_workout_caption("Sarah", "HIIT", "Intermediate")

print(caption)

```

This approach allows for batch processing multiple client captions with minimal manual intervention.
