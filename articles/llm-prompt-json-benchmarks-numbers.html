Key Performance Metrics

Typical resource profile when running the prompt pack locally with `mlx-lm` inference on an M2-class Mac (16GB RAM):

  • Response Time: low single-digit seconds per prompt
  • JSON Output: prompts request strict JSON, so responses parse directly
  • Token Efficiency: prompts stay compact — in the low hundreds of tokens each
  • Memory Usage: roughly 1-2GB during inference

Here's a working example of how to integrate one prompt into your workflow:

```python

import json

from mlx_lm import load, generate

Load model

model, tokenizer = load("mlx-community/Mistral-7B-v0.3-4bit")

Prompt from the pack

prompt = {

"role": "user",

"content": "Extract key facts from this text: The quick brown fox jumps over the lazy dog."

}

Generate response

response = generate(model, tokenizer, prompt["content"], max_tokens=100)

print(json.loads(response))

```
