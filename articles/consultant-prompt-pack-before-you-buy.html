The Workflow System

Here's how I implemented it in practice:

```bash

Create prompt directory structure

mkdir -p ~/consultant-prompts/{proposals,emails,lead-mag} && cd ~/consultant-prompts

Sample prompt file: proposal-template.txt

echo 'You are a senior consultant with 10+ years experience.

Client needs help with [CHALLENGE].

Your company [COMPANY] specializes in [SPECIALTY].

Create a 3-page proposal addressing:

1. Problem statement with data points

2. Proposed solution framework

3. Timeline and deliverables

4. Budget overview

Format as professional Word document with headings and bullet points.

Client: [CLIENT_NAME]

Challenge: [CHALLENGE]

Specialty: [SPECIALTY]' > proposals/proposal-template.txt

Run prompt with curl (example for OpenAI)

curl https://api.openai.com/v1/chat/completions \

-H "Content-Type: application/json" \

-H "Authorization: Bearer $OPENAI_API_KEY" \

-d '{

"model": "gpt-4",

"messages": [{"role": "user", "content": "$(cat proposals/proposal-template.txt)"}],

"temperature": 0.7

}'

```

This creates a build-once system that generates client-ready content without copywriter costs.
