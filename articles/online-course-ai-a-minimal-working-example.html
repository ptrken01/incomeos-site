Online Course AI: A Minimal Working Example

When building AI-powered online courses, practitioners often face a common challenge: how to create a functional, private system without extensive infrastructure or complex dependencies. This article provides a minimal working example that demonstrates the core concepts of an online course AI system that you can build once and deploy privately.

The Core Problem

Traditional LLM-powered course systems require:

  • Complex API management
  • User authentication systems
  • Database connections
  • Web frameworks
  • Multiple service integrations

For practitioners who want a faster, private workflow, we can strip this down to essential components while maintaining functionality.

Minimal Working Example

Here's a complete working example that demonstrates an online course AI system with private deployment:

> [illustrative template — not runnable as-is]

```python

import os

import json

from datetime import datetime

from typing import Dict, List, Optional

import openai

from dataclasses import dataclass

from pathlib import Path

@dataclass

class CourseContent:

title: str

modules: List[Dict]

last_updated: str = None

def __post_init__(self):

if self.last_updated is None:

self.last_updated = datetime.now().isoformat()

class CourseAI:

def __init__(self, api_key: str, course_path: str = "course.json"):

openai.api_key = api_key

self.course_path = Path(course_path)

self.course_data = self._load_course()

def _load_course(self) -> CourseContent:

if self.course_path.exists():

with open(self.course_path, 'r') as f:

data = json.load(f)

return CourseContent(**data)

return CourseContent(

title="My AI Course",

modules=[],

last_updated=datetime.now().isoformat()

)

def _save_course(self):

with open(self.course_path, 'w') as f:

json.dump(self.course_data.__dict__, f, indent=2)

def generate_module_content(self, module_title: str,

learning_objectives: List[str]) -> str:

prompt = f"""

Create detailed course content for a module titled "{module_title}".

Learning Objectives:

{chr(10).join([f'- {obj}' for obj in learning_objectives])}

The content should include:

1. Introduction (2-3 paragraphs)

2. Key concepts with examples

3. Practical implementation steps

4. Common pitfalls and solutions

5. Summary

Format as markdown with appropriate headers.

"""

response = openai.ChatCompletion.create(

model="gpt-4-turbo",

messages=[{"role": "user", "content": prompt}],

temperature=0.7,

max_tokens=1500

)

return response.choices[0].message.content.strip()

def add_module(self, module_title: str, learning_objectives: List[str]):

content = self.generate_module_content(module_title, learning_objectives)

new_module = {

"title": module_title,

"content": content,

"created_at": datetime.now().isoformat(),

"learning_objectives": learning_objectives

}

self.course_data.modules.append(new_module)

self._save_course()

print(f"Added module: {module_title}")

def get_module(self, module_index: int) -> Optional[Dict]:

if 0 <= module_index < len(self.course_data.modules):

return self.course_data.modules[module_index]

return None

def search_modules(self, query: str) -> List[Dict]:

results = []

for module in self.course_data.modules:

if query.lower() in module['title'].lower() or \

any(query.lower() in obj.lower() for obj in module['learning_objectives']):

results.append(module)

return results

Usage example

if __name__ == "__main__":

# Initialize with your OpenAI API key

ai_course = CourseAI(api_key="sk-...your-api-key...", course_path="my_course.json")

# Add a new module

ai_course.add_module(

module_title="Introduction to Machine Learning",

learning_objectives=[

"Understand basic ML concepts",

"Identify different types of ML problems",

"Explain supervised vs unsupervised learning"

]

)

# Retrieve and display content

module = ai_course.get_module(0)

if module:

print(f"Module: {module['title']}")

print(module['content'][:500] + "...")

```

Key Features of This Implementation

This minimal example includes:

1. Private Storage: Course data saved locally as JSON

2. API Integration: Uses OpenAI's GPT-4 Turbo model

3. Content Generation: Automatically creates structured course content

4. Module Management: Add, retrieve, and search modules

5. Persistent Data: All changes saved to disk

The system ~1500 tokens of content per module with a simple API call that takes 2-onds.

Setup Instructions

1. Create a virtual environment:

```bash

python -m venv course-env

source course-env/bin/activate # On Windows: course-env\Scripts\activate

```

2. Install dependencies:

```bash

pip install openai python-dotenv

```

3. Set your API key in an environment file:

> [illustrative template — not runnable as-is]

```bash

echo "OPENAI_API_KEY=sk-...your-key..." > .env

```

4. Run the example:

```bash

python course_ai.py

```
