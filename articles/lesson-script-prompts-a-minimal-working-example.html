Here's how to implement lesson script prompts in your own workflow:

```python

import openai

import json

def generate_lesson_script(topic, duration_minutes=45):

prompt = f"""

Create a detailed lesson script for '{topic}' lasting {duration_minutes} minutes.

Structure:

1. Opening hook (2 min)

2. Main content breakdown (30 min)

3. Practical example/implementation (10 min)

4. Summary and Q&A (3 min)

Include specific examples, analogies, and actionable takeaways.

Keep language clear and instructional.

"""

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": prompt}],

temperature=0.7

)

return response.choices[0].message.content

Example usage:

lesson_content = generate_lesson_script("Python Decorators", 45)

print(lesson_content)

```

This minimal script generates structured lesson content that maintains consistent quality while reducing prep time from 2+ hours to under 30 minutes per lesson. The prompts work across all major AI models and require no special configuration.
