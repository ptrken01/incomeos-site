Local Business Prompts A Practical Dev Guide

Managing online presence for local service businesses can be overwhelming. Google posts, quotes, and review requests require consistent content creation that's both personalized and efficient. This guide shows you how to automate this workflow using AI prompts in a build-once, run-many approach.

The Workflow Setup

I've created 50 targeted prompts specifically designed for local service businesses. Each prompt generates content for one of three categories: Google posts (17), quotes (18), or review requests (15). These prompts are structured to work with any AI interface that accepts system and user messages.

Here's a working example using Python and the OpenAI API:

```python

import openai

def generate_local_content(prompt_type, business_data):

# System prompt for consistent tone

system_prompt = "You are a professional local business content writer. Maintain conversational yet professional tone."

# Prompt templates

prompts = {

'google_post': f"Write a Google post for {business_data['name']} in {business_data['location']}. Focus on {business_data['service']}. Keep it under 150 words.",

'quote': f"Create a professional quote for {business_data['name']} offering {business_data['service']}. Include their contact information.",

'review_request': f"Draft a review request email for {business_data['name']} after completing work for {business_data['customer']}. Keep it friendly and professional."

}

response = openai.ChatCompletion.create(

model="gpt-3.5-turbo",

messages=[

{"role": "system", "content": system_prompt},

{"role": "user", "content": prompts[prompt_type]}

]

)

return response.choices[0].message.content

Usage example

business = {

'name': 'ABC Plumbing',

'location': 'Portland, OR',

'service': 'emergency plumbing repairs',

'customer': 'the Johnsons'

}

print(generate_local_content('review_request', business))

```

Implementation Strategy

The key is to store prompts in a structured format. I've organized them into three categories with clear templates:

  • Google posts: Focus on local SEO and community engagement
  • Quotes: Professional service descriptions with pricing context
  • Review requests: Customer-centric follow-ups with specific project details

Each prompt template includes variables for business name, location, service type, and customer information. This structure allows for batch processing while maintaining personalization.
