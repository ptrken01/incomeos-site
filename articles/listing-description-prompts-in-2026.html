How to Use Prompts in Your Workflow

Here's a practical example of how to integrate AI prompts into your existing workflow:

```python

import openai

from typing import Dict, List

def generate_listing_description(property_data: Dict) -> str:

prompt = f"""

Write a compelling listing description for a {property_data['bedrooms']} bed,

{property_data['bathrooms']} bath home in {property_data['location']}.

Key features:

- {property_data['features']['pool']}

- {property_data['features']['garage']}

- {property_data['features']['garden']}

Include these elements:

1. Market positioning (luxury/affordable)

2. Lifestyle appeal

3. Unique selling points

Keep it under 300 words.

"""

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": prompt}],

temperature=0.7

)

return response.choices[0].message.content.strip()

Usage example:

property_data = {

"bedrooms": 4,

"features": {

"pool": "Infinity pool with city views",

description = generate_listing_description(property_data)
```
