Self-Host LLM Guide: A Minimal Working Example

Deploying your own LLM server can be surprisingly straightforward when you use the right tools. This guide shows how to get a minimal, working local LLM server in under 15 minutes using the Local-LLM Builder Bundle.

Setup Overview

We'll deploy an LLM server on a local machine using MLX and the prompt pack from the bundle. The setup requires:

  • macOS with Apple Silicon (M1/M2/M3) or Linux
  • Python 3.10+
  • ~8GB RAM minimum (more recommended for larger models)
  • 50GB storage (for model files)

Step-by-Step Instructions

First, install the required dependencies:

```bash

pip install mlx-lm

```

Create a simple server script `server.py`:

```python

from mlx_lm import serve

import argparse

def main():

parser = argparse.ArgumentParser(description="Local LLM Server")

parser.add_argument("--model", default="mlx-community/Llama-3.2-1B-Instruct-4bit", help="Model name or path")

parser.add_argument("--port", type=int, default=8000, help="Server port")

args = parser.parse_args()

serve(args.model, host="localhost", port=args.port)

if __name__ == "__main__":

main()

```

Run the server:

```bash

python server.py --model mlx-community/Llama-3.2-1B-Instruct-4bit --port 8000

```

This starts a local API server at `http://localhost:8000`. The prompt pack included in the bundle contains pre-tuned prompts for various tasks like summarization, code generation, and question answering.

Test with curl:

```bash

curl http://localhost:8000/generate \

-H "Content-Type: application/json" \

-d '{

"prompt": "Explain quantum computing in simple terms",

"max_tokens": 200,

"temperature": 0.7

}'

```

Configuration Tips

The bundle includes a default configuration file `config.yaml` that you can customize:

```yaml

model: "mlx-community/Llama-3.2-1B-Instruct-4bit"

port: 8000

max_tokens: 512

temperature: 0.7

```

For larger models, adjust memory allocation:

```bash

export MLX_MAX_ALLOWED_SIZE=4096

```

FAQ

Q: What hardware do I need to run this locally?

A: An Apple Silicon Mac (M1/M2/M3) works best due to MLX optimizations. Linux systems with CUDA support are also viable, though performance varies. The minimum recommended RAM is 8GB.

Q: How does the prompt pack improve performance?

A: The prompt pack contains pre-tuned templates optimized for specific tasks like code generation or summarization. These reduce the need for manual prompt engineering and improve consistency. Using these templates can boost task-specific accuracy by up to 15% compared to generic prompts.

Q: Can I use this for production applications?
