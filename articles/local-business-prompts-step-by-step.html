How It Works

Here's a practical example of how to use one of these prompts in practice:

```python

import openai

from datetime import date

Prompt template for Google post about plumbing services

prompt_template = """

Write a Google post for a plumbing business in {city} that:

  • Highlights emergency plumbing services
  • Mentions 24/7 availability
  • Includes a call-to-action to call now
  • Uses local SEO keywords like "plumber {city}"
  • Is 150-200 words

Today's date: {date}

"""

Your specific business details

business_data = {

"city": "Austin",

"date": date.today().strftime("%Y-%m-%d")

}

Generate the post

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[

{"role": "user", "content": prompt_template.format(**business_data)}

]

)

print(response.choices[0].message.content)

```

This simple approach gives you consistent, high-quality content with minimal effort. Each prompt is designed to be plug-and-play — just replace the variables and run.
