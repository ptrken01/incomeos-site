Handmade Listing Prompts Setup That Actually Works

I've tested dozens of AI prompt setups for Etsy listings, and here's the workflow that consistently delivers results for sellers who want to build once and scale privately.

The Core Problem

Most sellers waste time copying and pasting prompts into different tools. What you need is a single, editable source that generates titles, descriptions, and policies—then exports cleanly to your shop.

My Working Solution: Text File + Python Script

I created a system using plain text files for prompts and a Python script to generate listings. This approach:

  • Eliminates tool lock-in
  • Works offline
  • Scales without subscription fees
  • Lets you version control changes

Step 1: Prompt Structure

Create `prompts.txt` with this format:

```

[title_prompt]

Generate an Etsy SEO title for [product_category] with [keywords] that includes [target_audience]

[description_prompt]

Write a compelling product description for [product_type] that highlights [key_benefits] and appeals to [target_audience]

[policy_prompt]

Create a clear shop policy for [product_category] that addresses [concerns] and includes [guarantee_terms]

```

Step 2: Python Automation Script

Use this script to generate listings:

```python

import re

def generate_listing(prompt_file, variables):

with open(prompt_file, 'r') as f:

content = f.read()

# Replace placeholders with actual values

for key, value in variables.items():

content = re.sub(r'\[' + key + r'\]', value, content)

return content

Usage example

variables = {

'product_category': 'handmade ceramic mugs',

'keywords': 'ceramic mug, handmade mug, coffee mug',

'target_audience': 'coffee lovers',

'product_type': 'handcrafted ceramic mug',

'key_benefits': 'durable, microwave safe, unique design',

'concerns': 'durability, shipping, return policy',

'guarantee_terms': '30-day satisfaction guarantee'

}

title = generate_listing('prompts.txt', {'product_category': variables['product_category'], 'keywords': variables['keywords'], 'target_audience': variables['target_audience']})

description = generate_listing('prompts.txt', {'product_type': variables['product_type'], 'key_benefits': variables['key_benefits'], 'target_audience': variables['target_audience']})

policy = generate_listing('prompts.txt', {'product_category': variables['product_category'], 'concerns': variables['concerns'], 'guarantee_terms': variables['guarantee_terms']})

print("Title:", title)

print("Description:", description)

print("Policy:", policy)

```

Step 3: Batch Processing

For multiple products, create `products.csv`:

```

product_category,keywords,target_audience

handmade ceramic mugs,"ceramic mug, handmade mug, coffee mug",coffee lovers

wooden cutting boards,"wooden board, kitchen cutting board, handmade",home cooks

```

Then run a loop to generate all listings:

```python

import csv

with open('products.csv', 'r') as f:

reader = csv.DictReader(f)

for row in reader:

variables = row

title = generate_listing('prompts.txt', variables)

print(f"Generated: {title}")

```
