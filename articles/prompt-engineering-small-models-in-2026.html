Example Prompt: Structured Output Loop

Here's an example of how a prompt might be used in a loop to extract structured data:

```python

prompt = """

You are a helpful assistant that extracts structured data from user input.

Return only valid JSON with no additional text or formatting.

User Input: {user_input}

Extract the following fields:

  • name: string
  • age: integer
  • hobby: string

JSON Output:

"""

```

This is then fed into your local model, and you parse the output:

```python

response = model(prompt.format(user_input="John is 30 and loves hiking"))

data = json.loads(response)

print(data) # {"name": "John", "age": 30, "hobby": "hiking"}

```
