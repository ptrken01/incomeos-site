The Prompt Framework

We've developed 50 AI prompts specifically for local service businesses. Each prompt is designed to generate content that's both SEO-optimized and conversion-focused. These prompts work in any AI tool that accepts structured input.

Here's a working example using Python to batch-process prompts:

```python

import os

from openai import OpenAI

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

def generate_content(prompt_template, business_data):

response = client.chat.completions.create(

model="gpt-4",

messages=[

{"role": "system", "content": "You are a local business content specialist."},

{"role": "user", "content": prompt_template.format(**business_data)}

]

)

return response.choices[0].message.content

Example usage

business_data = {

"business_name": "Smith's Plumbing",

"service": "emergency plumbing repair",

"location": "Portland, OR",

"specialty": "24/7 emergency service"

}

prompt = """

Write a Google post for {business_name} promoting {service}.

Include why customers choose {specialty} and mention {location}.

Keep it under 150 words.

"""

content = generate_content(prompt, business_data)

print(content)

```
