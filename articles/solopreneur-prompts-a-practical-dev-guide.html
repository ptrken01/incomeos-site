Solopreneur Prompts A Practical Dev Guide

As a solopreneur consultant, you're constantly juggling client work, proposal writing, and lead generation without the luxury of a copywriter team. I've created a practical workflow using AI prompts to streamline your content creation.

My Workflow Setup

I use a simple bash script with `curl` to generate content from prompts:

```bash

#!/bin/bash

PROMPT_FILE="prompt.txt"

OUTPUT_FILE="output.md"

curl -X POST https://api.openai.com/v1/completions \

-H "Content-Type: application/json" \

-H "Authorization: Bearer $OPENAI_API_KEY" \

-d '{

"model": "text-davinci-003",

"prompt": "$(cat $PROMPT_FILE)",

"max_tokens": 1000,

"temperature": 0.7

}' > $OUTPUT_FILE

```

This setup generates a new proposal draft in under 30 seconds, with zero manual formatting.

Prompt Structure for Consistency

My prompts follow this template:

```

[ROLE] Write a [TYPE] for [TARGET] that includes [SPECIFIC_REQUIREMENTS]

```

Example: "Write a consulting proposal for a SaaS startup that includes a problem statement, solution approach, timeline, and pricing structure"

I've optimized 50 such prompts for different client scenarios. Each prompt is designed to output ready-to-edit markdown content.
