How to Use the Prompt Library

The prompts are organized into three categories: issue openers (17), subject lines (17), and growth tweets (16). Here's a practical example of how to implement them:

```python

import openai

import random

Example prompt for issue opener

issue_prompt = """

You are an experienced newsletter writer. Write a compelling opening paragraph for a newsletter about

AI tools for creators, with a conversational tone that feels personal but professional.

"""

Generate content using the prompt

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": issue_prompt}],

temperature=0.7,

max_tokens=150

)

print(response.choices[0].message.content.strip())

```

This approach works with any OpenAI-compatible API and can be adapted to your existing workflow. Each prompt is designed to be used in sequence—after generating content, you can iterate through the library to build a complete newsletter issue.

Prompt Categories Explained

Issue openers focus on engagement and personal connection, typically starting with a question or brief anecdote. Subject lines are crafted for higher open rates, using curiosity gaps and urgency. Growth tweets are designed to encourage sharing and attract new readers.

The prompts work best when you use them in batches—generate 3-5 at a time rather than one at a time. This creates consistency in your voice while maintaining variety in content structure.
