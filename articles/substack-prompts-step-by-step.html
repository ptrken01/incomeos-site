Substack Prompts Step-by-Step

Building a newsletter list doesn't have to be repetitive. Using AI prompts can automate the creative process for issue openers, subject lines, and growth tweets—saving you hours each week. Here's how to set up a reusable workflow using 50 pre-built prompts.

Getting Started with Your Prompt Library

First, export your prompt library as a JSON file. Each prompt should be structured like this:

```json

{

"id": 1,

"type": "subject_line",

"prompt": "Write a subject line that gets 30% open rates for tech newsletters targeting developers"

}

```

Create a Python script to iterate through prompts and generate content:

```python

import openai

import json

with open('prompts.json', 'r') as f:

prompts = json.load(f)

for prompt in prompts:

response = openai.Completion.create(

engine="text-davinci-003",

prompt=prompt['prompt'],

max_tokens=50

)

print(f"{prompt['type']}: {response.choices[0].text.strip()}")

```

Run every Monday at 9 AM

This script generates content for all prompt types in one go. You'll get 50 variations across three categories: 17 subject lines, 17 issue openers, and 16 growth tweets.
