My Workflow Setup

I built a simple script that processes 50 prompts through a single API call to generate complete video content:

```python

import openai

import json

def generate_youtube_content(prompts):

results = []

for prompt in prompts:

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": prompt}],

max_tokens=1500,

temperature=0.7

)

results.append(response.choices[0].message.content)

return results
```
