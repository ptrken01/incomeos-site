Agent Loop Prompts Setup That Actually Works

When building local LLM workflows, the agent loop pattern is essential for multi-step reasoning and task automation. However, setting up prompts that actually work reliably—especially with smaller models—requires careful tuning.

Setup Example: Multi-Step Code Generation Agent

```json

{

"role": "system",

"content": "You are a helpful coding assistant. Follow the user's instructions exactly. Only respond with valid Python code blocks when asked to write code. Do not explain your reasoning."

}

```

```json

{

"role": "user",

"content": "Write a function that calculates the factorial of n, then call it with n=5 and print the result."

}

```

```json

{

"role": "assistant",

"content": "```python\nimport math\n\ndef calculate_factorial(n):\n return math.factorial(n)\n\nresult = calculate_factorial(5)\nprint(result)\n```"

}

```

This loop works because:

  • The system prompt enforces strict output format
  • The user prompt provides clear steps
  • The assistant response includes code in a code block

Key Prompt Patterns That Work

1. Code Generation with Constraints

```json

{"role": "system", "content": "Respond only with valid JSON. No explanations."}

```

2. Step-by-Step Reasoning

```json

{"role": "user", "content": "First, identify the problem. Then, solve it step by step."}

```

3. Output Format Control

```json

{"role": "assistant", "content": "Here is the result in JSON format: {\"result\": \"value\"}"}

```

Best Practices for Local Agent Loops

  • Use system prompts to enforce behavior
  • Limit assistant responses to specific formats (code blocks, JSON)
  • Avoid ambiguous instructions that confuse smaller models
  • Test each loop step with a few examples before production
