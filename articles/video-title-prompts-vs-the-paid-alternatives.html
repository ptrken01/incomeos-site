My Private Workflow

I've created a simple Python script that uses OpenAI's GPT-4 API to generate title prompts. Here's how it works:

```python

import openai

import os

Configuration

openai.api_key = os.getenv('OPENAI_API_KEY')

model = "gpt-4"

def generate_title_prompt(topic):

prompt = f"""

Generate a click-worthy YouTube title for a video about "{topic}".

Include: 1. A strong hook (3-5 words)

2. The main benefit or value proposition

3. A specific, concrete outcome

4. A sense of urgency or exclusivity

Format: "Hook - Benefit - Outcome [Urgency]"

Example: "Stop Wasting Time - Learn This 10x Faster Method - Get Results in 24 Hours"

Generate exactly 5 unique variations.

"""

response = openai.ChatCompletion.create(

model=model,

messages=[{"role": "user", "content": prompt}],

temperature=0.8

)

return [line.strip() for line in response.choices[0].message.content.split('\n') if line.strip()]

Usage example

topics = ["AI marketing tools", "Python automation", "Content strategy"]

for topic in topics:

print(f"\n{topic}:")

titles = generate_title_prompt(topic)

for title in titles:

print(f" • {title}")

```
