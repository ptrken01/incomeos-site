Etsy Product Description Prompts: A Minimal Working Example

If you're an Etsy seller looking to scale your product listings without sacrificing quality, you'll want to build a simple workflow that leverages AI prompts for SEO titles, descriptions, and shop policies. This is not about complex automation or expensive tools—just a working system that works.

The Core Workflow

Here's a minimal example of how to structure your prompts using Python and OpenAI's API:

```python

import openai

import os

Configure API key

openai.api_key = os.getenv("OPENAI_API_KEY")

def generate_etsy_listing(prompt_template, product_data):

response = openai.ChatCompletion.create(

model="gpt-3.5-turbo",

messages=[

{"role": "system", "content": "You are an expert Etsy seller creating optimized listings."},

{"role": "user", "content": prompt_template.format(**product_data)}

]

)

return response.choices[0].message.content.strip()

Example usage

prompt = """

Create a compelling Etsy product description for a {product_type} that includes:

  • 150-200 words of engaging copy
  • SEO keywords: {keywords}
  • Target audience: {target_audience}
  • Include benefits and use cases

Product details: {description}

"""

data = {

"product_type": "handmade wooden jewelry box",

"keywords": "wooden jewelry organizer, handmade gift, rustic storage, wooden box",

"target_audience": "crafty women, gift buyers, homesteaders",

"description": "This beautiful wooden jewelry box features a handcrafted design with natural wood grain and soft velvet interior."

}

result = generate_etsy_listing(prompt, data)

print(result)

```

This approach lets you maintain 50 distinct prompts in one Python script. Each prompt is parameterized for reusability across different products. The workflow requires only:

  • One API key
  • A single Python file
  • 50 well-crafted prompts
  • Product data as dictionary

Key Design Principles

The prompts are designed around three core components: SEO titles (30-40 characters), product descriptions (150-200 words), and shop policies. Each prompt is optimized for fast, consistent output while maintaining human-like quality.

For example, a title prompt might look like:

```

Generate an Etsy SEO title under 40 characters that includes these keywords: {keywords}.

Make it compelling for {target_audience}.

```

A description prompt:

```

Write a 150-200 word product description for {product_name} that:

  • Uses active voice
  • Includes {benefits}
  • Mentions {materials}
  • Is optimized for {audience}

```
