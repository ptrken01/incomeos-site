Review Request Prompts: A Practical Dev Guide

When managing local service businesses, review requests are crucial for growth. However, manually crafting these messages wastes time and resources. This guide shows you how to implement a reusable system using AI prompts that generate personalized review requests for your business.

The Setup

I've created 50 AI prompts specifically designed for local service businesses. Each prompt targets different scenarios like post-service follow-ups, customer milestones, or seasonal requests. Here's a practical example of how to use them in practice:

```python

import openai

import os

def generate_review_request(customer_name, service_type, days_since):

prompt = f"""

Generate a professional review request for {customer_name} who received {service_type}

{days_since} days ago. Keep it concise (under 100 words) and friendly.

Include:

- Personal greeting

- Brief service summary

- Request to share experience

- No sales language

Format: Single paragraph, no bullet points.

"""

response = openai.ChatCompletion.create(

model="gpt-3.5-turbo",

messages=[{"role": "user", "content": prompt}],

temperature=0.5,

max_tokens=120

)

return response.choices[0].message.content.strip()

Usage example

request = generate_review_request(

"Sarah Johnson",

"roof repair",

7

)

print(request)

```

This system works with any local service business. The prompts are designed to adapt to different industries, from plumbing to landscaping, ensuring authentic messaging.

Implementation Strategy

The prompts work best when integrated into existing workflows. I recommend creating a simple database of customer interactions and mapping them to appropriate prompts. For instance:

  • Customer service within 7 days → "Recent Service Follow-up"
  • Customer with multiple services → "Loyalty Recognition"
  • Customer who hasn't reviewed in 30+ days → "Friendly Reminder"
