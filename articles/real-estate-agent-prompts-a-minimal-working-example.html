Real Estate Agent Prompts: A Minimal Working Example

Real estate agents spend countless hours writing listings, follow-ups, and ads. Automating this process with AI prompts can save 2-4 hours per day. Here's how to build a minimal working example using ready-to-use prompts.

Getting Started

We'll use a simple Python script that takes property data and generates marketing content using pre-built prompts. The system requires only three inputs: property details, agent name, and desired output type (listing, follow-up, or ad).

```python

import openai

import os

Configuration

openai.api_key = os.getenv('OPENAI_API_KEY')

PROMPT_TEMPLATE = """

You are a professional real estate agent named {agent_name}.

Write {output_type} for this property:

{property_details}

Requirements:

  • Use active voice
  • Include 3-5 key selling points
  • Keep under 150 words
  • Mention local amenities if relevant

Format as plain text.

"""

def generate_content(property_data, agent_name, output_type):

"""Generate marketing content using AI prompts"""

# Prepare property details

property_details = "\n".join([

f"Address: {property_data.get('address', '')}",

f"Price: ${property_data.get('price', '')}",

f"Bedrooms: {property_data.get('bedrooms', '')}",

f"Bathrooms: {property_data.get('bathrooms', '')}",

f"Square Feet: {property_data.get('sqft', '')}",

f"Description: {property_data.get('description', '')}"

])

# Construct prompt

prompt = PROMPT_TEMPLATE.format(

agent_name=agent_name,

output_type=output_type,

property_details=property_details

)

# Generate response

response = openai.ChatCompletion.create(

model="gpt-3.5-turbo",

messages=[{"role": "user", "content": prompt}],

temperature=0.7,

max_tokens=200

)

return response.choices[0].message.content.strip()

Example usage

property_data = {

"address": "123 Oak Street, Anytown",

"price": "450000",

"bedrooms": "4",

"bathrooms": "3",

"sqft": "2200",

"description": "Modern family home with updated kitchen"

}

content = generate_content(property_data, "Sarah Johnson", "listing")

print(content)

```
