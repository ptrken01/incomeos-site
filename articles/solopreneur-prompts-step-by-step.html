Step 2: The Prompt Template

Here's a working example for client proposals:

```

You are a senior consultant specializing in [INDUSTRY].

Create a 3-page proposal for a [CLIENT_TYPE] that includes:

1. Project overview (100 words)

2. Timeline and deliverables (200 words)

3. Budget breakdown (150 words)

Client background: [CLIENT_DESCRIPTION]

Include these elements:

  • Clear value proposition
  • Risk mitigation strategies
  • Success metrics

Use professional, confident tone.

```

Step 3: Implementation Workflow

I use this simple bash script to generate content:

```bash

#!/bin/bash

Generate proposal with AI

prompt_file="prompts/proposals/proposal_template_1.txt"

input_data="client_data.json"

Read client data

client_name=$(jq -r '.name' $input_data)

industry=$(jq -r '.industry' $input_data)

Replace placeholders in prompt

sed "s/\[CLIENT_NAME\]/$client_name/g" $prompt_file | \

sed "s/\[INDUSTRY\]/$industry/g" > temp_prompt.txt

Send to AI (example with curl)

curl -X POST https://api.openai.com/v1/chat/completions \

-H "Authorization: Bearer $API_KEY" \

-H "Content-Type: application/json" \

-d '{

"model": "gpt-4",

"messages": [{"role": "user", "content": "$(cat temp_prompt.txt)"}],

"max_tokens": 2000

}'

```

This generates a complete proposal in under 30 seconds.

Step 4: Customization Pipeline

After AI generation, I use a second script to refine content:

```bash

Refine content with custom rules

python refine.py \

--input "generated_proposal.txt" \

--rules "refinement_rules.json" \

--output "final_proposal.txt"

```

The refinement process adds:

  • Industry-specific terminology
  • Client-specific references
  • Tone adjustments
