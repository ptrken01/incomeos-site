How to Build Your Prompt System

Here's a practical snippet for generating optimized Etsy titles using AI:

```python

def generate_etsy_title(product_name, category, key_features):

prompt = f"""

Create an Etsy title for: {product_name}

Category: {category}

Key features: {key_features}

Requirements:

- 80 characters max

- Include primary keyword first

- Add 2-3 relevant modifiers

- Use clear, compelling language

- Avoid generic terms like "perfect for" or "great gift"

Title:

"""

return prompt.strip()

Example usage:

title_prompt = generate_etsy_title(

"Handmade Ceramic Mug",

"Home & Living",

"microwave safe, dishwasher safe, 11oz capacity"

)

print(title_prompt)

```

This system works by standardizing inputs and outputs. For 50 shop items, you'd maintain a template with 2-3 variables: product name, category, and key features.
