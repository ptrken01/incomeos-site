How to Implement AI Prompts for Fitness Coaching

Here's a practical example of how to use these prompts in your workflow:

```python

import openai

import json

Your prompt template

prompt_template = """

Create a 30-day fitness program for a {client_type} client with {goal}.

Include {workout_days} workout days per week.

Focus on {focus_area} and avoid {avoid_exercises}.

Output as JSON with keys: "program_name", "weekly_schedule", "notes"

"""

Example usage

def generate_client_program(client_type, goal, workout_days, focus_area, avoid_exercises):

prompt = prompt_template.format(

client_type=client_type,

goal=goal,

workout_days=workout_days,

focus_area=focus_area,

avoid_exercises=avoid_exercises

)

response = openai.ChatCompletion.create(

model="gpt-4",

messages=[{"role": "user", "content": prompt}],

temperature=0.7

)

return json.loads(response.choices[0].message.content)

Generate program for beginner client

program = generate_client_program(

client_type="beginner",

goal="lose 15 lbs",

workout_days=3,

focus_area="full body strength",

avoid_exercises="heavy lifting, high impact"

)

```

This approach lets you build a library of prompts that generate consistent, high-quality content. The key is to use structured templates that output predictable formats like JSON.
