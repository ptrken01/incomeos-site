I've spent countless hours building AI workflows for consultants. The most common pain point? Repeatedly writing proposals without a scalable system. Here's how I set up a private, build-once workflow that actually works.

My Working Prompt Template Structure

```

[Consultant Profile]

Name: [Your Name]

Specialty: [Your Niche]

Years Experience: [X years]

[Client Context]

Company: [Client Name]

Industry: [Industry]

Size: [Employees]

Challenge: [Specific Problem]

[Proposal Requirements]

Scope: [What you'll deliver]

Timeline: [When it starts/ends]

Budget: [Client's budget range]

[Output Format]

Format: [Proposal, Email, Lead Magnet]

Tone: [Professional, Friendly, Technical]

Length: [X words]

[Instructions]

1. Start with executive summary (200 words)

2. Address client challenge directly

3. Present your solution clearly

4. Include 3 benefits specific to their situation

5. End with next steps and contact info

[Example Output]

[Include 1-2 sentence example of desired output]

```

Real Implementation Example

Here's a concrete, runnable prompt I use for client proposals:

```

You are [Your Name], a [Specialty] consultant with [X years] experience.

Client: [Company Name] in [Industry], [Size] employees, facing [Challenge]

Create a 500-word proposal that addresses their specific challenge. Structure:

1. Executive Summary (100 words)

2. Problem Analysis (150 words)

3. Proposed Solution (150 words)

4. Expected Outcomes (75 words)

5. Next Steps (25 words)

Use [Tone] and include [Specific Benefit 1], [Specific Benefit 2], and [Specific Benefit 3] relevant to their situation.

Output format: Single paragraph sections, no bullet points.

```

My Workflow Setup

1. Template Storage: I maintain a Notion database with 50 ready-to-use prompt templates

2. AI Interface: Use ChatGPT with temperature=0.3 for consistency

3. Customization: Paste client details into template placeholders

4. Review Process: Quick 2-minute edit pass before sending

5. Library Growth: Add new templates after each successful use

This setup reduces proposal time from 3 hours to 15 minutes per client.

FAQ

Q: How do you handle different industries with one prompt system?

A: I create industry-specific templates but maintain core structure. Each template has 3-5 customizable variables for industry details. This approach scales to 20+ niches without rebuilding from scratch.

Q: What's your success rate with AI-generated proposals?

A: About 75% of AI-written proposals require only minor edits. I've seen 12 successful client conversions using this system, with average response rates improving from 3% to 28% after implementing the workflow.

Q: How do you avoid generic content when using prompts?

A: I include specific variables for client details and add a "customization required" section. The AI generates structure and framework; human touch ensures relevance. This hybrid approach maintains efficiency while preserving personalization.
