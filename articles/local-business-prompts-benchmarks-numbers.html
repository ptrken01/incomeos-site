The most effective prompts follow a specific structure. Here's a working example for plumbing services:

```prompt

You are a local plumbing business owner writing Google review requests. Create 3 versions of a 100-word message that:

1. Mentions specific service (e.g., "emergency pipe repair")

2. References customer satisfaction ("98% customer satisfaction")

3. Includes call-to-action ("Please share your experience")

Format as bullet points with clear, friendly tone.

```

Implementation Strategy

Create a local business prompt library using this structure:

1. Organize prompts by service category

2. Store in a private Notion database or text files

3. Version control with git for updates

4. Batch process using Python scripts

Example Python script to generate multiple prompts:

```python

import os

def generate_prompt_templates():

categories = ['plumbing', 'electrical', 'cleaning', 'landscaping']

base_prompt = "You are a local {category} business owner writing Google posts. Create 3 versions of a 150-word message that mentions specific service, customer benefits, and call-to-action."

for category in categories:

prompt = base_prompt.format(category=category)

with open(f"prompt_{category}.txt", "w") as f:

f.write(prompt)

generate_prompt_templates()

```
