The core system works like this:

```python

def generate_listing_prompt(property_data):

return f"""

You are a professional real estate agent specializing in {property_data['location']}.

Write a compelling listing description for a {property_data['type']} with:

  • {property_data['bedrooms']} bedrooms and {property_data['bathrooms']} bathrooms
  • Square footage: {property_data['sqft']}
  • Key features: {', '.join(property_data['features'])}
  • Local market context: {property_data['market_context']}

Focus on emotional appeal, local advantages, and clear value propositions.

Keep it under 300 words. Use active voice and sensory language.

"""

```

This approach lets your team input property details and instantly generate marketing copy that maintains brand voice while adapting to each unique listing.
